First Principles: Cubic Differentiation

Explore $f(x) = x^3$. Drag the slider to move Point $B$ relative to Point $A$. When $h$ is positive, $B$ is to the right. When $h$ is negative, $B$ is to the left.

Point A (\(x\)): 1.00
Point B (\(x+h\)): 2.00
Slope (\(m\)): 7.00

As \(h \to 0\), the slope approaches the derivative \(3x^2\). At \(x=1\), this value is 3.

The Formal Definition

\[ f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} \]

Algebraic Steps for \(f(x) = x^3\)

1. Expand \(f(x+h)\) \((x+h)^3 = x^3 + 3x^2h + 3xh^2 + h^3\)
2. Difference \(f(x+h) - f(x) = 3x^2h + 3xh^2 + h^3\)
3. Divide by \(h\) \(\frac{3x^2h + 3xh^2 + h^3}{h} = 3x^2 + 3xh + h^2\)
4. Apply Limit (\(h \to 0\)) \(3x^2 + 3x(0) + (0)^2 = \mathbf{3x^2}\)
