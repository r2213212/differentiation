1. The Definition

Differentiation is finding the instantaneous rate of change. Since we can't divide by zero to find the slope at one point, we use a limit:

f'(x) = limh → 0 [ f(x + h) - f(x) ] / h

2. The Four-Step Method

This is how the math works for f(x) = x² (the curve shown above):

Step Logic Result
1 Setup Find f(x + h) (x + h)² = x² + 2xh + h²
2 Difference Subtract f(x) (x² + 2xh + h²) - x² = 2xh + h²
3 Divide Divide by h (2xh + h²) / h = 2x + h
4 Limit Let h → 0 2x + 0 = 2x

3. What are you seeing?

  • The Red Line: This is the "Secant." It represents the average slope between two points.
  • The Shrinking h: As you slide h toward 0, the two points become one.
  • The Derivative: When h is tiny, the slope is exactly 2x. Since our point is at x=2, the slope becomes 4.
